# Project Rules & Daily Logging

## Daily Work Log
1. After completing any code modification, file creation, or significant task, you MUST update or create a daily log file in the root directory.
2. Filename format: `LOG_DD-MM-YY.md` (e.g., `LOG_13-11-26.md`). Always check today's current system date via terminal (`date`) before creating or updating the file.
3. Rule: NEVER overwrite existing entries in today's log file. Always append new entries at the bottom.
4. Language: Write all log entries in Bulgarian.
5. Entry Format:
   ### [HH:MM] - Кратко заглавие на промяната
   - **Променени файлове:** списък с файловете
   - **Детайли:** 1-2 кратки изречения какво и защо е направено.
